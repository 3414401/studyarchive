Linear Independence(선형 독립)

Linear Independence

v1, v2, v3 ...vn가 모두 선형 독립이다.

⇔ [v1 v2 v3 ... vn │ 0] 이 오직 자명한 해를 갖는다.

⇔ v1x1 + v2x2 + v3x3 + ... + vnxn = 0이 오직 자명한 해를 갖는다.

⇔ 자유 변수 없다.

Linear Dependence

v1, v2, v3 ...vn중 최소 2개가 선형 종속이다.

⇔ [v1 v2 v3 ... vn │ 0] 이 비자명한 해를 갖는다.

⇔ v1x1 + v2x2 + v3x3 + ... + vnxn = 0이 비자명한 해를 갖는다.

왜 그런가?

일단 x는 항상 가중치이다.

v1x1 + v2x2 + v3x3 + ... + vnxn = 0이 비자명한 해를 갖는 순간,

vn = a1v1 + a2v2 + ... 꼴로 표현 가능하기 때문이다.

벡터가 1개일 때는?

0벡터 1개는 선형 종속이다. [V │ 0]하면 많은 비자명한해 있으니까! ㄷㄷ(

nonzero벡터 1개는 선형 독립이다. [V │ 0]하면 자명한해만 있으니까! ㄷㄷ(

🔖그러므로 independece를 따질 땐 [v1 v2 v3 ... vn │ 0]를 쓰자!

🔖Theorem 8

⭐ n x p에서 벡터의 개수가 차원보다 많으면(p>n) 무조건 선형 종속이다.

⭐ v1, v2, v3 ... 중에 하나라도 0벡터이면 선형종속이다. (바로 비자명한 해 1 0 0 0 ..같은거 생기니까)
