Theorem 8

Let A be an square n×n matrix. Then the following statements are equivalent. That is, for given A, the statements are either all true or all false.

a. A is an invertible matrix.

b. A is row equivalent to the n×n matrix.(행 축약 하고나면 단위행렬이 된다 ㄷㄷ)

c. A has n pivot positions.(그렇겟지 onto니까)

d. The equation Ax=0 has only the trivial solution. (그렇겟지 one-to-one이니까)

e. The columns of A form a linearly independent set. (⭐그렇겟지 one-to-one이니까⭐)

f. The linear transformation x↦Ax is one-to-one. (그렇겟지 자유변수가 없으니까)

g. The equation Ax=b has at least one solution for each b in Rn.(그렇겟지 onto니까)

h. The columns of A span Rn.

i. The linear transformaiton x↦Ax maps Rn onto Rn.

j. There is an n×n matrix C such that CA=I.(역행렬의 정의)

k. There is an n×n matrix D such that AD=I. (역행렬의 정의)

l. ATis an invertible matrix.


Invertible Matrix Theorem

a. A는 n×n 가역행렬이다.

다음 명제들은 모두 동치이다.

① 단사 (One-to-One)

  • d. Ax = 0은 자명해만 가진다.
  • e. A의 열벡터들이 선형독립이다.
  • f. 선형변환 x ↦ Ax는 단사이다.

✔️ 자유변수가 없으며, 모든 열에 피벗이 존재한다.

② 전사 (Onto)

  • g. 모든 b ∈ ℝn에 대해 Ax = b의 해가 존재한다.
  • h. A의 열벡터들이 ℝn을 생성한다.
  • i. 선형변환 x ↦ Ax는 ℝn에서 ℝn으로의 전사이다.

✔️ 모든 행에 피벗이 존재한다.

③ 행렬 구조와 역행렬 조건

  • b. A는 단위행렬 In과 행 동치이다.
  • c. A는 n개의 피벗 위치를 가진다.
  • j. CA = I를 만족하는 n×n 행렬 C가 존재한다.
  • k. AD = I를 만족하는 n×n 행렬 D가 존재한다.
  • l. AT도 가역행렬이다.

✔️ n×n 행렬에서는 가역 ⇔ 단사 ⇔ 전사 ⇔ 전단사가 성립한다.

Theorem: AB = I이면 BA = I

Let A and B be square matrices. If AB = I, then A and B are both invertible, with B = A-1 and A = B-1.

✔️ A, B가 같은 크기의 n×n 정사각행렬이고 AB = I라면, 두 행렬은 서로의 역행렬이다.

① A가 가역행렬임을 증명

AB = I이므로, B의 열벡터를 b1, ..., bn이라 하면

AB = [Ab1   Ab2   ...   Abn] = I

따라서 Ab1 = e1, ..., Abn = en이다.

즉, 단위행렬의 모든 열벡터를 A의 열벡터들의 선형결합으로 표현할 수 있다.

단위행렬의 열벡터들은 ℝn을 생성하므로, A의 열벡터들도 ℝn을 생성한다.

따라서 A는 전사(Onto)이다.

✔️ A는 n×n 정사각행렬이므로, 전사 ⇔ 가역이다.

∴ A는 가역행렬이다.

② B = A-1임을 증명

A가 가역행렬이므로 A-1이 존재한다.

AB = I의 양변 왼쪽에 A-1을 곱하면,

A-1AB = A-1I

(A-1A)B = A-1

IB = A-1

∴ B = A-1

③ BA = I임을 증명

B = A-1이므로,

BA = A-1A = I

따라서 B도 가역행렬이며, A = B-1이다.

∴ AB = I ⇔ BA = I

✔️ 결론: 같은 크기의 정사각행렬에서는 오른쪽 역행렬이 존재하면 왼쪽 역행렬도 반드시 존재한다.
