SOLUTION

1️⃣ Ax=I의 해를 구하기 위해 [A I]를 푼다. 이때 행 축약을 통해 [I B]꼴로 바꾸면 x=B가 된다.

2️⃣ det(A-1)= 1 det(A)

이때,

det(A) ≠ 0 인 경우: 역행렬 A⁻¹이 존재하며, 이를 가역행렬(Invertible matrix) 또는 정칙행렬이라고 부릅니다.

det(A) = 0인 경우: 역행렬이 존재하지 않으며, 이를 특이행렬(Singular matrix)이라고 부릅니다.

Elementary Matrices(기본 행렬)

항등 행렬에서 행연산 한번만 한거

행 연산: 행 교환, 상수배, 행 더하기

## 기본행렬 (Elementary Matrix) **정의:** 단위행렬 \(I_m\)에 기본행 연산(Elementary Row Operation)을 **한 번** 적용하여 만든 \(m\times m\) 행렬을 기본행렬 \(E\)라고 한다. ### 1. 기본행 연산의 세 가지 종류 ① **행 교환 (Row Swap)** - 두 행의 위치를 교환한다. - 예: \(R_1 \leftrightarrow R_2\) \[ E=\begin{bmatrix}0&1&0\\1&0&0\\0&0&1\end{bmatrix} \] ② **상수배 (Scaling)** - 특정 행에 0이 아닌 상수를 곱한다. - 예: \(R_2\leftarrow 5R_2\) \[ E=\begin{bmatrix}1&0&0\\0&5&0\\0&0&1\end{bmatrix} \] ③ **행 더하기 (Row Addition)** - 특정 행에 다른 행의 상수배를 더한다. - 예: \(R_1\leftarrow R_1+3R_2\) \[ E=\begin{bmatrix}1&3&0\\0&1&0\\0&0&1\end{bmatrix} \] ### 2. 기본행렬의 핵심 정리 \[ EA=\text{A에 기본행 연산을 적용한 결과} \] - \(E\): 단위행렬에 동일한 기본행 연산을 적용하여 만든 기본행렬 - \(A\): 기본행 연산을 적용할 행렬 - \(EA\): 기본행 연산이 적용된 결과 행렬 **원리:** 행렬곱 \(EA\)에서 결과 행렬의 각 행은 \(E\)의 해당 행을 계수로 사용하여 \(A\)의 행들을 선형결합한 것이다. ※ \(A\)가 \(m\times n\)이면 \(E\)는 \(m\times m\)이다. ### 3. 기본행렬과 역행렬 **모든 기본행렬은 가역행렬이다.** 기본행 연산은 항상 역연산으로 되돌릴 수 있기 때문이다. - 행 교환 → 다시 같은 두 행 교환 - 상수배 \(k\) → \(1/k\)배 - 다른 행의 \(k\)배 더하기 → \(k\)배 빼기 여러 기본행 연산으로 가역행렬 \(A\)를 단위행렬로 만들면, \[ E_k\cdots E_2E_1A=I \] 따라서 \[ A^{-1}=E_k\cdots E_2E_1 \] **핵심:** 기본행렬은 기본행 연산을 행렬곱으로 표현하는 도구이며, 가우스-조던 소거법으로 역행렬을 구하는 원리가 된다.
