1.1 선형연립방정식 Systems of Linear Equations

1차 x가 상수와 결합된 형태

a1x1 + a2x2 + a3x3 + ... + = b

최종 목표: EXISTENCE(존재성), UNIQUENESS(유일성) 판별

solution(해) 개수: 0, 1, infinity 셋 중 하나

- 1, infinity: consistent(유효)

- 0 : Inconsistent(불능)

변수 개수 전체 공간 Row 한개
2개 ℝ2 1차원 직선
3개 ℝ3 2차원 평면
6개 ℝ6 5차원 초평면

📖용어: Augmented Matrix(첨가 행렬) / Coefficient Matrix(계수 행렬) / 행 축약(-> 사다리꼴 --> 축약된 사다리꼴)

행 축약의 3단계: ①대체(곱해서 더하기) ②교환(위치 바꾸기) ③스케일링(행 단위로 상수 곱하기)

최종 목표: EXISTENCE(존재성), UNIQUENESS(유일성) 판별

Ax=b의 EXISTENCE(존재성): 마지막 행 보기

⬇️*해가 존재한다면*⬇️

UNIQUENESS(유일성): 비자명한 해 체크 <-> 자유변수 체크 <-> Ax=0의 자유변수 체크

📖용어 basic variable: 기본 변수, free variable: 자유 변수

📖용어 REF는 여러개 --> 피벗 위아래 다 0 --> RREF

📖용어 매개변수적 표현 (Parametric Descriptions): 모든 basic 변수들을 free variable의 선형결합으로 표현

🔖Theorem2: 가장 오른쪽 열이 피벗 열이 아니라면, 해가 존재하며 consistent함.

02 / 열벡터 관점

Ax는 A의 열벡터를 x의 성분으로 선형결합한 결과입니다.
