Linear Transformation (선형변환)

🔖properties 2가지(암기)

1️⃣ 가산성: T(u+v)=T(u)+T(v)

- 두 벡터를 먼저 더하고 변환한 거나, 각각 변환 후 더한거나 같다.

2️⃣ 스칼라곱: cT(u)=T(cu)

또한, 모든 행렬 곱은 선형 변환이다. 곱을 그렇게 정의했기 때문!

참고로 역도 성립함ㄷㄷ 모든 유한차원 실수벡터공간 사이의 선형변환은 기저를 정하면 행렬곱으로 표현할 수 있다.

1️⃣+2️⃣ 중첩의 원리: T(C1v1 + ... cpvp)) = c1T(v1) + c2T(v2) + ... + cpT(vp)

Ax=b

Ax=b

방정식이 아니라,

행렬 A를 벡터 x에 A라는 행위를 하는 object로 보자. (혹은 함수)

행렬 A가 m×n행렬이라면 ℝn → ℝm으로 보내는 선형 변환임.

행렬 A가 m×n, x는 n×p --> b는 m×p니까

x⟼Ax

A=T(x)로 보면, domain은 n, Codomain은 m, Range는 set of all images T(x)이다.

🌍Find an x in ℝ2 whose image under T is b. <-T에 의한 상이 b가 되는 ℝ2 x를 구하라는 뜻(영어 so hard)
